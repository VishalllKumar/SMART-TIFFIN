SMART TIFFIN 🍱

SMART TIFFIN is an IoT-based smart food heating and monitoring system developed using ESP32, Relay Module, HTML, CSS, and JavaScript. The project is designed to provide a modern and efficient solution for remotely controlling food heating through a web dashboard. It combines embedded systems, wireless communication, and frontend web technologies to create a practical smart kitchen application.

The ESP32 microcontroller connects to WiFi and acts as a local web server. Users can access the responsive dashboard from a mobile phone or computer to control the heater remotely. The dashboard allows users to switch the heater ON or OFF, set a timer in seconds, and monitor a live countdown display in real time. The relay module connected to the ESP32 controls the heating device by managing the power supply.

A major feature of SMART TIFFIN is the automatic timer-based shutoff system. Once the selected timer completes, the relay automatically turns OFF to prevent overheating and reduce unnecessary power consumption. The system also provides a notification alert saying “Your food is ready!” after the heating process is completed.

The project includes a live ESP32 status monitoring feature that continuously checks whether the ESP32 is connected to the network. The dashboard dynamically displays ONLINE or OFFLINE status using colored indicators for better user interaction. The frontend interface is designed with modern UI elements such as animated switches, gradient themes, glassmorphism cards, and responsive layouts to improve user experience across different devices.

SMART TIFFIN demonstrates practical implementation of IoT concepts including remote monitoring, device automation, real-time communication, and web server integration. The project can be further upgraded by adding cloud connectivity, mobile app support, temperature sensors, voice assistant integration, and push notifications.

Overall, SMART TIFFIN is an innovative IoT project that offers a smart, user-friendly, and energy-efficient approach to remote food heating and monitoring for daily life applications.
